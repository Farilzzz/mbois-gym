# Manager projection v2 contract

`manager_dashboard/{YYYY-Qn}` and `/trainers/{uid}` keep existing aggregate fields. Trainer target is 5000000. `/trainers/{uid}/clients/{clientId}` retains name, packageName, totalSessions, attendedSessions, remainingSessions; adds status (active/completed/cancelled/no_package), selectedPackageId, packages (allowlisted summaries: id, packageName, status, totalSessions, attendedSessions, remainingSessions), unresolvedSessionCount. Attendance adds packageId; no notes, workouts, medical data, signatures or contact details. All lifecycle counts are package-specific, based on completed session documents, never mutable completedCount. Missing packageId stays unresolved, not guessed. Cancelled/completed clients remain in history. Current assignment controls operational visibility; transaction trainer controls historical revenue.

Trusted sales require status valid/paid, paymentStatus paid, paymentEvidenceId, verifiedBy, verifiedAt, transactionId, packageId, clientId, trainerId, timestamp, totalSessions, price. Verification fields must be server/admin-only under Firestore rules. Snapshot price must equal catalog (4=500000, 10=1000000, 16=1600000, 24=2000000). Currency IDR. Partial refund uses integer refundAmount, net revenue in original transaction quarter (Asia/Jakarta). Sale cancelled/void/refunded excluded. Package cancellation never changes paid revenue. Missing evidence/link/snapshot is unresolved, not payment confirmation. Duplicate transaction IDs are all quarantined. `projection_audit/sales` holds only sale IDs and reason codes, never payment evidence; default-deny this private namespace.

Backend owns only manager_dashboard, projection_audit and projection_control namespaces. Exact source triggers: users, clients, clients/{id}/packages, clients/{id}/sessions, package_sales. No output triggers. Transactional full recompute + shared control-document fence; retries read fresh source, replace allowlisted documents, delete obsolete paths from prior manifest. Atomic capacity cap fails closed rather than publishing partial totals. Deployment and root rules/config coordination pending; no production writes performed.
